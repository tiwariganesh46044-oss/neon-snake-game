# 🐍 NEON SNAKE

A modern, responsive and interactive Snake Game built using HTML, CSS and JavaScript.

## ✨ Features

- Classic Snake Gameplay
- Three Difficulty Levels: Easy, Medium and Hard
- Dynamic Speed Progression
- Score and High Score Tracking
- Snake Length and Level Display
- 3-2-1 Game Countdown
- Pause and Resume Functionality
- Game Over Result Panel
- New High Score Notification
- Sound Effects with ON/OFF Control
- Dark Mode and Light Mode
- Keyboard Controls (Arrow Keys and WASD)
- Mobile Touch Controls
- Swipe Controls
- Responsive Design for Mobile, Tablet and Desktop
- Persistent High Score using Local Storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas
- Web Audio API
- Local Storage

## 🎮 How to Play

1. Select your preferred difficulty level.
2. Click the Start Game button.
3. Wait for the countdown.
4. Control the snake using Arrow Keys or WASD.
5. On mobile, use the directional buttons or swipe.
6. Eat food to increase your score and snake length.
7. Avoid hitting the walls or your own body.
8. Try to beat your High Score!

## 🎯 Controls

| Action | Control |
|---|---|
| Move Up | ↑ / W |
| Move Down | ↓ / S |
| Move Left | ← / A |
| Move Right | → / D |
| Pause / Resume | Pause Button |
| Restart | Restart Button |

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

   You can also use the VS Code Live Server extension.
